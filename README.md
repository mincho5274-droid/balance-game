# 골라봐 — 밸런스 게임

둘 중 하나만 고르는 밸런스 게임 웹앱. 고르면 다른 사람들이 어느 쪽을 골랐는지 바로 보여준다.

- 주제 8개 (요즘 이슈, 음식, 연애·관계, 초능력·상상, 일상·습관, 극한·더러움, 돈·현실, 학교·직장), 질문 약 3,700개
- 맵기 필터: 순한 / 매운 / 극한
- 많이 고른 질문 TOP 10
- 투표 집계: Supabase (`cast_vote` 함수로만 기록, IP당 분당 40표 제한)

## 질문 추가하기

1. `data/<주제>.json` 끝에 `{"sub": "소주제", "a": "선택지A", "b": "선택지B", "level": 1}` 추가 (level 1=순한, 2=매운, 3=극한)
2. 저장소 루트에서 `python3 tools/merge.py` 실행 → `questions.json` 갱신
3. 이미 있는 질문의 순서는 바꾸지 말 것 (번호가 바뀌면 기존 투표 기록과 어긋남)
